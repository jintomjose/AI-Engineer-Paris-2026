## The four shifts

1. **Customer:** agents are the new users and buyers. Design for Agent Experience (AX), not just UX/CX.
2. **Build:** agents are only as good as their context, data and specialization. Everyone has agents, nobody has orchestration.
3. **Control:** agent sprawl is real. Observability and guardrails were the hottest topic.
4. **Market:** models converge, pricing moves from consumption to workflow to outcomes.

Takeaway: the model is becoming a commodity. The advantage is context, data and discipline.
